# Veyli Colour

An original fictional makeup storefront, created in November 2026 with Nuxt, Vue Composition API, strict TypeScript and Pinia. Expressive colour stories, visible named shades and a simulated shopping journey.

Delivery is in progress. No real orders, payments or messages are made. Media and typography are original/generated or openly licensed; provenance accompanies the completed source.

Use Node 22.23.1 and npm 10.9.8. `npm ci`, `npm run dev`, `npm run build`, `npm run preview`.
