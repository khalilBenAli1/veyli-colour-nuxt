# Veyli Colour delivery

Started 2026-11-03. Original fictional beauty brand, separate from the earlier retail apps. Ten products, visible named shades and an expressive colour-wall composition using Syne and Figtree.

1. Foundation: standard-peer exact lockfile, strict Nuxt/Vue/Pinia, self-hosted licensed fonts, finite typed catalogue, recognizable responsive opening and real static routes. Verify and push.
2. Discovery/product slice: category/finish/family/price URL filters and sort, rapid update composition, wishlist, matching shade photos and availability, accessible gallery/quantity/bag. Verify actual desktop/mobile and push.
3. Colour-story/checkout slice: editable compatible story slots, exact cents, atomic add-look, validated namespaced persistence, local customer form/review/immutable confirmation/reset. Unit/store and browser journeys, push.
4. Hardening: malformed-record and email regressions, SSR isolation/hydration, other-demo storage sentinel, long text, exact idempotent 2× text, keyboard/focus/reduced motion/Axe and clientWidth reflow. Actual screenshots, measured payload and documentation. Feature PR and green CI.
5. Publish: normal merge preserving meaningful history, free GitHub Pages deployment, anonymous public direct-route/assets/font/core shopping-story journey verification, repository metadata and root portfolio handoff.

## Boundaries

- Closed opaque packages are genuinely shade-neutral; Satin Stroke's three open shade images match the selected shade. Swatches are illustrative, never an exact prediction on skin.
- Story tags determine compatibility, not skin tone. No camera, medical/certification claims, fake reviews or commercial metrics.
- No server, API key, real purchase, message or saved contact record is needed. One clear checkout demo notice and final outcome explain the simulation.
- Application state is factory-scoped per Nuxt request; persistence initializes after mount and writes only validated product/shade/quantity/wishlist data to its own key.
- Media files and their two provenance documents have a separate owner. App code and fonts are owned here; root owns the personal portfolio and parent progress.
